# ScorpionBitesGroup

A personal frontend portfolio showcasing selected web projects, built with React and Tailwind CSS.

🔗 **Live site:** [scorpionbitesgroup.vercel.app](https://scorpionbitesgroup.vercel.app/)

## Overview

ScorpionBitesGroup is a portfolio site built to present a curated collection of frontend projects — highlighting UI implementation, component design, and interface craftsmanship rather than backend or business logic.


## Features

- Responsive, mobile-first layout
- Project showcase with descriptions and live/demo links
- Clean, minimal UI focused on readability and navigation
- Fast load times via Vercel's edge deployment


## Tech Stack

- **Framework:** React
- **Framework:** Hygraph - graphql
- **Styling:** Tailwind CSS - styled-component
- **Deployment:** Vercel


## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/moeinmnia80/SBG.git
cd SBG
npm install
npm run dev
```

The app will be available at `http://localhost:3000` (or the port shown in your terminal).


## Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/          # Page-level views
├── assets/         # Images and static assets
└── styles/         # Tailwind config and global styles
```
